## Why

用户搜索分析过的视频没有统一的管理入口，每次都需要重新输入 BVID 搜索。作为一个知识管理工具，用户需要快速回溯之前看过的视频及其分析结果，视频历史列表是最基础也是最核心的功能。

## What Changes

- 新增视频历史列表页面 `/videos`，展示用户搜索过的所有视频
- 视频卡片展示缩略图、标题、UP主、分析时间、知识提取状态
- 支持点击卡片跳转到视频分析详情页
- 支持删除单条历史记录
- 支持按时间排序和关键词筛选
- 确保每次视频分析完成后自动保存记录到数据库（现有流程可能已有，需确认）

## Capabilities

### New Capabilities

- `video-history`: 视频历史记录的展示、筛选、删除，以及从列表跳转到详情页的完整交互

### Modified Capabilities

（无需修改现有 spec 级别的需求）

## Impact

- **前端**：新增 `/videos` 页面及路由，导航栏需增加入口
- **后端**：可能需要新增视频列表查询 API（分页、筛选），新增删除 API
- **数据库**：Video 模型已有，可能需要确认 `createdAt`/`updatedAt` 字段和用户关联
- **导航**：全局导航需增加"视频历史"入口

## 非目标

- 不做视频收藏/置顶功能
- 不做跨用户视频分享
- 不做视频标签管理
- 不做视频播放功能
