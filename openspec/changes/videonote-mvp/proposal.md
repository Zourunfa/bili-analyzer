# 提案：videonote-mvp

## 为什么做
当前 bilibili-subtitle-analyzer 是一个单次视频分析工具——分析完就离开，没有知识沉淀。用户（尤其是视频学习者）需要：
1. 把分析过的视频知识**保存**下来
2. 按学习主题**组织**多个视频
3. **跨视频**检索和对话
4. 把积累的知识**导出**为可复用的 Skill

## 做什么
将现有工具升级为「视记 VideoNote」——一个视频学习知识管理平台。MVP 聚焦于：

1. **用户系统**：注册/登录，隔离数据
2. **视频分析增强**：在现有分析基础上，自动提取结构化知识（主题、要点、概念、问答对）
3. **笔记本系统**：创建笔记本，关联分析过的视频，按主题组织
4. **UP主分析**：查看UP主视频列表，选择视频批量分析，或全量分析UP主内容
5. **知识检索**：全文搜索 + 语义搜索已提取的知识点
6. **Skill 导出**：将笔记本知识打包为 Markdown 或 System Prompt

## 不做什么（非目标）
- 不做跨视频 RAG 对话（V2）
- 不做移动端适配
- 不做协作/分享功能
- 不做视频内嵌播放
- 不支持非B站平台

## 成功标准
- 用户能注册登录并拥有独立数据空间
- 分析视频后自动提取并存储结构化知识
- 用户能创建笔记本并管理关联视频
- 能查看UP主视频列表并批量分析
- 能搜索自己的知识库
- 能将笔记本导出为 Markdown 文件
