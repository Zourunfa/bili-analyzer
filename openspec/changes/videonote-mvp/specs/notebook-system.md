# 规范：笔记本系统

## 概述
笔记本是用户组织视频知识的核心容器。用户可以创建多个笔记本，每个笔记本关联多个视频。

## 用户场景

### 场景1：学习一个技术栈
用户正在学习 Rust，看了10个不同的B站视频。创建「Rust学习」笔记本，每分析一个视频就添加进去。

### 场景2：研究一个话题
用户想了解「大模型微调」，搜索并分析了5个相关视频，放入同一笔记本，方便对比和综合理解。

### 场景3：跟踪一个UP主
用户喜欢某个UP主的教学视频，通过UP主分析功能批量导入其视频到笔记本。

## 功能需求

### 笔记本 CRUD
- **创建**：标题 + 描述 + 标签
- **查看**：笔记本列表（卡片视图），笔记本详情（关联视频列表）
- **编辑**：修改标题、描述、标签
- **删除**：确认后删除，级联删除关联关系

### 视频关联
- 分析视频时可选择添加到笔记本
- 在笔记本详情页可添加已分析的视频
- 可从笔记本移除视频（不删除视频本身）
- 支持拖拽排序

### 笔记本视图
- **概览**：标题、描述、视频数、标签、最近更新
- **视频列表**：封面、标题、UP主、添加时间、用户笔记
- **知识汇总**：聚合所有视频的知识点，按类型筛选

## 页面结构
```
/notebooks              — 笔记本列表
/notebooks/[id]         — 笔记本详情
/notebooks/[id]/export  — 导出页面
```
