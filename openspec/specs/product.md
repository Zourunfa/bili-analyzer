# 产品定义：视记 VideoNote

## 产品定位
视记是一个**视频学习笔记本**——将B站视频转化为可检索、可对话、可导出的结构化知识。

核心价值：不是「又一个视频总结工具」，而是把零散的视频学习变成系统化的知识管理体系。

## 目标用户
- **视频学习者**：通过B站学习技术、知识类内容的用户
- **知识工作者**：需要从大量视频中提取和整理信息的人
- **内容研究者**：需要追踪特定UP主或领域内容的分析者

## 核心功能

### V1 MVP
1. **视频分析**（已有，需增强）
   - B站视频信息获取 + 字幕提取（CC字幕 / Whisper转写）
   - AI生成结构化摘要
   - 基于字幕的对话问答

2. **结构化知识提取**（新增）
   - 从字幕自动提取：主题、要点、概念、问答对
   - 知识点带时间戳关联到视频

3. **笔记本系统**（新增）
   - 创建/管理笔记本
   - 关联视频到笔记本
   - 按主题/学习计划组织视频

4. **UP主分析**（新增）
   - 查看UP主所有视频列表
   - 选择特定视频集合分析
   - 全量分析UP主内容并总结

### V2 进阶
5. **跨视频 RAG 对话**
   - 基于多视频知识库的智能问答
   - 引用来源视频和时间戳

6. **知识检索**
   - 全文搜索 + 语义搜索
   - 按主题、概念、UP主筛选

7. **Skill 导出**
   - 将笔记本知识打包为 Markdown
   - 生成可复用的 System Prompt
   - 导出为其他 AI 工具的 Skill 格式

## 差异化优势
| 维度 | 通用AI对话 | 视记 VideoNote |
|------|-----------|---------------|
| 知识持久化 | 对话结束即消失 | 永久存储、可检索 |
| 多视频关联 | 逐个分析 | 笔记本聚合、跨视频RAG |
| 知识复用 | 手动复制粘贴 | 一键导出Skill |
| UP主追踪 | 无 | 全量分析、趋势洞察 |
| 引用溯源 | 不可靠 | 精确到秒的时间戳 |

## 非目标
- 不做视频播放器
- 不做社交功能
- 不做视频下载/离线功能
- 不做移动端App（初期）
- 不支持非B站平台（初期）
