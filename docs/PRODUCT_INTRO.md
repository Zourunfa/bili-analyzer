# 视记 VideoNote - 产品介绍






## 一句话介绍
视记是一个 B 站视频知识管理平台，将视频转化为可检索、可对话、可导出的结构化 视频知识管理平台。



## 开发这个产品的原因
经常看b站,
1.然后遇到知识科普视频之后又不想看完，想节省点时间，所以我会用其他网站分析视频，其他网站需要收费
然后用大语言模型分析视频的方案主要是下面两种
(1) 直接用多模态分析，质量高，速度快，不依赖 服务器成本也太高 （2）语音转文字分析 成本低 速度慢一点
2.然后就是想把自己看过的有价值的知识视频知识 转化为自己的知识并形成自己的知识体系

## 核心功能

### 1. 视频 AI 分析
粘贴任意 B 站视频链接，自动提取
这个是支持无字幕的提取方式的
- 视频基本信息（标题、UP主、时长、播放量）
- AI 生成的结构化摘要
- 字幕内容 + AI 问答对话

### 2. 结构化知识提取
从视频字幕自动提取：
- 主题分类
- 核心要点
- 关键概念解释
- 精彩问答对
- 所有知识点带时间戳，可跳转回看

### 3. 笔记本系统
- 创建不同主题的笔记本（如"机器学习"、"产品设计"）
- 将视频关联到笔记本
- 按学习计划组织视频学习进度

### 4. UP主分析
- 输入 UP主主页，分析该 UP主所有视频
- 批量提取视频知识
- 洞察 UP主内容方向和风格

### 5. 知识检索
- 全文搜索 + 语义搜索
- 快速定位知识点
- 附带来源视频和时间戳

### 6. Skill 导出
- 将知识打包为 Markdown 文档
- 生成可复用的 System Prompt
- 导出为 AI Agent 的 Skill 格式

## 使用场景

| 场景 | 视记能帮你 |
|------|-----------|
| 看技术教程 | 自动整理知识点，不用边看边记笔记 |
| 学习知识类视频 | 构建个人知识库，随时检索 |
| 研究某个 UP主 | 批量分析视频，快速了解内容风格 |
| 准备分享/输出 | 一键导出结构化笔记 |
| 复习重点 | 通过时间戳快速回看关键段落 |

## 与其他工具的对比

| 能力 | 通用 AI 对话 | 视记 VideoNote |
|------|-------------|----------------|
| 知识持久化 | ❌ 对话结束即消失 | ✅ 永久存储 |
| 多视频关联 | ❌ 逐个分析 | ✅ 笔记本聚合 |
| 知识复用 | ❌ 手动复制粘贴 | ✅ 一键导出 |
| UP主追踪 | ❌ 不支持 | ✅ 全量分析 |
| 引用溯源 | ❌ 不可靠 | ✅ 精确到秒 |

## 技术栈

- **前端**: Next.js + Ant Design
- **后端**: Next.js API Routes
- **数据库**: PostgreSQL + Prisma
- **AI**: 通义千问 / OpenAI Compatible API
- **字幕处理**: Whisper 语音识别
- **部署**: 阿里云
