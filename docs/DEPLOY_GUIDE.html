③ Nginx + SSL 配置

1

上传证书到服务器

ssh root@120.76.141.65 "mkdir -p /root/nginx_ssl"

scp www.afai.asia.key root@120.76.141.65:/root/nginx_ssl/
scp www.afai.asia.pem root@120.76.141.65:/root/nginx_ssl/
2

编写 Nginx 配置

文件：/etc/nginx/sites-available/www.afai.asia

# HTTP → HTTPS 重定向
server {
    listen 80;
    listen [::]:80;
    server_name www.afai.asia afai.asia;
    return 301 https://$server_name$request_uri;
}

# HTTPS 反向代理
server {
    listen 443 ssl;
    listen [::]:443 ssl];
    server_name www.afai.asia afai.asia;

    ssl_certificate     /root/nginx_ssl/www.afai.asia.pem;
    ssl_certificate_key /root/nginx_ssl/www.afai.asia.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
3

启用 + 重启

ln -sf /etc/nginx/sites-available/www.afai.asia /etc/nginx/sites-enabled/
nginx -t           # 测试语法
systemctl restart nginx  # 重启生效
✅ 验证：服务器上执行 curl -k https://127.0.0.1 返回 200 即成功。

④ PM2 进程管理

常用命令

# 启动
pm2 start npm --name "subtitle" -- start

# 重启（更新代码后必须）
pm2 restart subtitle

# 查看状态
pm2 list
pm2 logs subtitle --nostream

# 开机自启
pm2 save
pm2 startup   # 按提示执行生成的命令

package.json scripts 约定

"scripts": {
  "build":  "prisma generate && next build",
  "start":  "next start",
  "dev:local": "next dev --port 3300"
}
⚠️ 重要：每次 git pull 更新代码后，必须 pm2 restart subtitle 才能生效（需先 npm run build）。

一键部署脚本

#!/bin/bash
cd /root/bili-analyzer
git pull
npm install
npx prisma db push
npm run build
pm2 restart subtitle
pm2 save

⑥ 常见问题排查

❌ useSearchParams Suspense 报错

现象：npm run build 报错 "useSearchParams() must be wrapped in Suspense"

原因：Next.js 16 生产构建预渲染时检查到 CSR bailout

解决：将 useSearchParams 组件包在 <Suspense> 中

export default Page() {
  return (Suspense fallback={<Spin/>}>
    <PageContent />
  </Suspense>)
}

❌ column does not exist

现象：Prisma 报错列 users.email_verified_at 不存在

原因：Prisma Schema 改了但数据库没同步

解决：npx prisma db push 或 npx prisma migrate deploy

❌ 外网 HTTPS 访问超时

排查步骤：

  1. 安全组是否开放 443 入方向？
  2. 安全组是否绑定到 ECS 实例？
  3. ss -tlnp | grep 443 nginx 监听正常？
  4. 服务器上 curl -k https://127.0.0.1 是否返回 200？

❌ 更新代码后网站还是旧版

原因：PM2 跑的是 .next 里的旧构建产物

解决：必须重新构建

npm run build && pm2 restart subtitle
