# B站字幕分析器 — 模型可配置需求文档

## 1. 背景与目标

### 1.1 现状问题

当前系统存在两处模型硬编码：

| 模块 | 当前实现 | 问题 |
|------|----------|------|
| **语音转写** | `videocaptioner --asr bijian` | 只支持必剪 ASR，无法切换 Whisper / 其他引擎 |
| **AI 分析/摘要** | `qwen-plus` (通义千问) | 无法使用 GPT-4 / Claude / 其他国产模型 |

用户无法根据：
- 预算（不同模型价格差异大）
- 效果（不同模型在特定场景表现不同）
- 隐私要求（数据敏感场景需要本地模型）
来选择合适的模型组合。

### 1.2 目标

实现**转写模型**和**分析模型**的可配置化：
- 支持多模型切换（云端 API / 本地模型）
- 保留默认配置，零配置也能正常运行
- 用户可在页面选择所用模型

## 2. 功能需求

### 2.1 可配置的模型类型

#### 2.1.1 转写模型（ASR）

| 模型 ID | 名称 | 类型 | 说明 |
|---------|------|------|------|
| `bijian` | 必剪 ASR | 云端 API | 当前默认，免费，无需 API Key |
| `whisper-base` | Whisper Base | 本地 | 速度快，CPU 可运行，精度一般 |
| `whisper-large` | Whisper Large | 本地 | 精度高，GPU 推荐，资源占用大 |
| `dify-asr` | Dify ASR | 云端 API | 通过 Dify 工作流调用 |
| `custom` | 自定义 | 可扩展 | 预留扩展点，支持用户接入自己的 ASR 服务 |

#### 2.1.2 分析模型（LLM）

| 模型 ID | 名称 | 类型 | 说明 |
|---------|------|------|------|
| `qwen-plus` | 通义千问 Plus | 云端 API | 当前默认，性价比高 |
| `qwen-max` | 通义千问 Max | 云端 API | 效果最好，价格较高 |
| `qwen-turbo` | 通义千问 Turbo | 云端 API | 速度快，价格低 |
| `gpt-4o` | GPT-4o | 云端 API | OpenAI 最新多模态模型 |
| `gpt-4o-mini` | GPT-4o Mini | 云端 API | 轻量版 GPT-4o |
| `claude-3-5-sonnet` | Claude 3.5 Sonnet | 云端 API | Anthropic 模型，效果好 |
| `ollama-llama3` | Llama 3 (本地) | 本地 | 通过 Ollama 部署 |
| `custom` | 自定义 | 可扩展 | 预留扩展点 |

### 2.2 配置层级

配置按优先级（低→高）分为三层：

```
全局默认配置（系统级，管理员设置）
    ↓ 覆盖
用户偏好配置（用户个人设置，登录后生效）
    ↓ 覆盖
请求级配置（单次分析时指定，最高优先级）
```

### 2.3 用户界面需求

#### 2.3.1 模型选择入口

在**分析页**顶部添加模型选择区：

```
┌─────────────────────────────────────────────────────────┐
│  [转写模型: 必剪 ASR ▼]   [分析模型: 通义千问 Plus ▼]   │
│                                                         │
│  ⚙ 如需切换模型，请先 [登录]                            │
└─────────────────────────────────────────────────────────┘
```

- 未登录：显示默认模型，不可切换
- 登录后：显示下拉菜单，可切换模型

#### 2.3.2 模型说明卡片

每个模型选项显示：
- 模型名称 + ID
- 类型标签（云端 API / 本地）
- 价格/资源消耗提示（可选）

示例：
```
通义千问 Plus (qwen-plus)  [云端 API]
计费：¥0.02/千tokens  |  速度：中等
```

#### 2.3.3 设置页面（用户偏好）

新增 `/settings` 页面，登录用户可设置默认模型组合：

```
我的模型偏好
────────────────────
默认转写模型：[必剪 ASR  ▼]
默认分析模型：[通义千问 Plus ▼]

[保存偏好设置]
```

### 2.4 API 改动需求

#### 2.4.1 新增配置相关 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/models` | 获取可用模型列表 |
| GET | `/api/models/config` | 获取当前生效的配置（全局 + 用户偏好） |
| PUT | `/api/models/config` | 更新用户偏好配置 |
| POST | `/api/transcribe` | 支持指定转写模型 (`model` 参数) |
| POST | `/api/summarize` | 支持指定分析模型 (`model` 参数) |
| POST | `/api/chat` | 支持指定分析模型 (`model` 参数) |

#### 2.4.2 请求参数示例

**POST /api/transcribe**
```json
{
  "bvid": "BVxxxx",
  "cid": 123456,
  "model": "whisper-base"   // 可选，不传则用配置
}
```

**POST /api/summarize**
```json
{
  "subtitleText": "...",
  "model": "gpt-4o"        // 可选，不传则用配置
}
```

### 2.5 数据模型改动

#### 2.5.1 新增配置表

```prisma
// prisma/schema.prisma 新增

model ModelConfig {
  id          String   @id @default(cuid())
  userId      String?  // nullable 表示全局配置
  transcribeModel String @default("bijian")
  analyzeModel   String @default("qwen-plus")
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@unique([userId])  // 全局配置 userId = null，只有一条
}
```

#### 2.5.2 Video 表扩展

```prisma
model Video {
  // ... 现有字段
  transcribeModel String @default("bijian")  // 记录分析时用的转写模型
  analyzeModel    String @default("qwen-plus") // 记录分析时用的分析模型
}
```

## 3. 非功能性需求

### 3.1 兼容性

- 默认配置与当前行为完全一致（`bijian` + `qwen-plus`）
- 切换模型不影响现有数据
- 离线/无法访问外部 API 时，回退到本地模型（如 Whisper）

### 3.2 性能要求

- 模型切换操作应< 500ms 完成
- 不因模型配置增加额外 API 调用（避免每次请求都查库）

### 3.3 安全要求

- API Key 等敏感配置只在服务端存储，不暴露给前端
- 用户偏好配置只允许登录用户修改
- 本地模型路径等系统级配置不可被普通用户修改

### 3.4 可扩展性

- 新增模型只需在配置文件中声明，无需改代码
- 支持按需加载模型（非所有模型都在启动时初始化）

## 4. 配置方案

### 4.1 环境变量（系统级默认）

```bash
# 默认转写模型
DEFAULT_TRANSCRIBE_MODEL=bijian

# 默认分析模型
DEFAULT_ANALYZE_MODEL=qwen-plus

# 可选的：第三方 API Keys
OPENAI_API_KEY=sk-xxx
ANTHROPIC_API_KEY=sk-ant-xxx

# 本地模型路径（Ollama / Whisper）
OLLAMA_BASE_URL=http://localhost:11434
WHISPER_MODEL_PATH=/models/whisper
```

## 6. 风险与注意事项

| 风险 | 应对措施 |
|------|----------|
| 本地模型资源占用高 | TRANSCRIBE_MAX_CONCURRENCY=1 限制并发 |
| 第三方 API 密钥泄露 | 所有 Key 只存在服务端 .env，前端不存储 |
| 用户选了不支持的模型组合 | 前端只显示可用选项，后端校验参数合法性 |
| 服务器内存不足 | 本地模型（Whisper Large）需要 8G+ 内存时给出警告 |
