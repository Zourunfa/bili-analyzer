向量搜索 (Raw SQL)

pgvector 余弦相似度
// pgvector 余弦相似度搜索 const results = await prisma .$queryRawUnsafe(` SELECT kp.*, 1 - (e.vector <=> '${vec}'::vector) as score FROM knowledge_points kp JOIN embeddings e ON e.knowledge_point_id = kp.id ORDER BY e.vector <=> '${vec}'::vector LIMIT 10 `);
<=> 是 pgvector 的余弦距离操作符。1 - (<=>) 将距离转为相似度分数（越接近 1 越相似）。

标准 API 模式
export async function POST(req) { try { // 1. 解析和验证请求 const { bvid } = await req.json(); if (!bvid) return error("缺少参数", 400); // 2. 业务逻辑 const video = await prisma.video .findUnique({ where: { bvid } }); // 3. 返回成功响应 return NextResponse.json({ message: "操作成功", data: video }); } catch (err) { // 统一错误处理 return error(err.message, 500); } }

HTTP 状态码约定

状态码含义使用场景
200成功GET 查询、PATCH 更新成功
201已创建POST 创建资源成功
400请求错误参数缺失、格式错误
401未认证未登录或 Session 过期
404未找到资源不存在
500服务器错误代码异常、外部 API 报错

SSE 流式响应

Server-Sent Events 模式
export async function POST(req) { const stream = new ReadableStream({ async start(controller) { const send = (data) => controller.enqueue( encoder.encode( `data: ${JSON.stringify(data)}\n\n` ) ); send({ status: "started", progress: 0 }); for (const item of items) { await processItem(item); send({ status: "processing", progress }); } send({ status: "completed", progress: 100 }); controller.close(); }, }); return new Response(stream, { headers: { "Content-Type": "text/event-stream", "Cache-Control": "no-cache", }, }); }
SSE vs WebSocket：SSE 是单向的（服务端 ➞ 客户端），更简单，适合进度推送。WebSocket 是双向的，适合实时聊天等场景。

WBI 签名算法

参数签名流程
// 1. 获取签名密钥 const { imgKey, subKey } = await getWbiKeys(); // 2. 生成混淆密钥 const mixinKey = getMixinKey(imgKey + subKey); // 3. 参数签名 const wts = Math.floor(Date.now()/1000); const query = sortAndJoin({ ...params, wts }); const w_rid = md5(query + mixinKey); // 4. 发起签名请求 const url = `/x/player/wbi/v2?${query}&w_rid=${w_rid}`;
核心思想：请求参数 + 密钥通过 MD5 哈希生成签名，服务端验证签名判断请求是否被篡改。

流式 vs 非流式

streamText — 流式输出
import { streamText } from "ai"; const result = streamText({ model: qwen("qwen-plus"), system: SUMMARY_PROMPT, messages: [{ role: "user", content: `分析字幕：\n${text}` }], }); // 一行返回 SSE 流 return result.toTextStreamResponse();
generateText — 结构化提取
import { generateText } from "ai"; const { text } = await generateText({ model: qwen("qwen-plus"), prompt: EXTRACTION_PROMPT(title, text), }); // 解析 LLM 返回的 JSON const match = text.match(/\[[\s\S]*\]/); const points = JSON.parse(match[0]); // 存入数据库 for (const p of points) await prisma.knowledgePoint .create({ data: { ...p, videoId } });

异步嵌入生成

不阻塞 API 响应
// 保存知识点（立即返回） const kp = await prisma.knowledgePoint .create({ data: { ... } }); // 异步生成 embedding（不等待完成） generateEmbedding(kp.content) .then(async (embedding) => { await prisma.$executeRaw` INSERT INTO embeddings (id, knowledge_point_id, vector) VALUES (${uuid()}, ${kp.id}, ${toVector(embedding)}::vector) `; }) .catch(err => console.error(err)); // 立即返回，不等 embedding 完成 return json({ message: "知识提取完成" });
为什么异步？30 个知识点逐个生成 embedding 需 30-60 秒。异步处理让用户立即看到结果，embedding 在后台静默生成。
