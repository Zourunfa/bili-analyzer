🔑 核心配置 auth.ts

export default NextAuth({
  providers: [credentialsProvider],
  callbacks: { jwt, session },
  session: { strategy: "jwt" },
  pages: { signIn: "/login" }
})

CredentialsProvider: 支持邮箱+密码登录

JWT Strategy: Session 以 JWT 形式存储在 cookie 中

🔑 登录 API 详解

POST /api/auth/callback/credentials

1. 用户提交 email + password
2. Prisma 查询用户: prisma.user.findUnique({ where: { email } })
3. bcrypt 比较密码: await bcrypt.compare(password, user.password)
4. 验证失败 → 抛出 CredentialsSignin
5. 验证成功 → NextAuth 生成 JWT
6. JWT Payload: { userId, email, role }

bcrypt: 密码哈希算法，每次哈希结果不同，需要 compare 验证

密码存储: 用户密码永远明文存储，使用 bcrypt 哈希后存储

🎫 JWT 回调函数

// callbacks.ts
export const callbacks = {
  async jwt({ token, user }) {
    if (user) {
      token.userId = user.id
      token.email = user.email
    }
    return token
  },
  async session({ session, token }) {
    if (session.user) {
      session.user.id = token.userId
      session.user.email = token.email
    }
    return session
  }
}

jwt(): 登录时将用户ID写入JWT

session(): 每次请求时将JWT数据注入Session

服务端组件保护

import { getServerSession } from "next-auth"

export default async function Page() {
  const session = await getServerSession(authOptions)
  if (!session) {
    redirect("/login")
  }
  // ... 渲染页面
}

API 路由保护

// app/api/xxx/route.ts
export async function POST(req: Request) {
  const session = await getServerSession(authOptions)
  if (!session?.user?.id) {
    return Response.json({ error: "未登录" }, { status: 401 })
  }
  // ... 处理业务逻辑
}

getServerSession(): 服务端获取当前会话，比 client 的 useSession() 更安全

🌉 Middleware 中间件

// middleware.ts
export { from pagesManifest } from "_next/static/ssgManifest"

export async function middleware(request: NextRequest) {
  const session = await getToken({
    req: request,
    secret: process.env.NEXTAUTH_SECRET
  })

  const isAuthPage = request.nextUrl.pathname.startsWith("/login")
  const isApiAuth = request.nextUrl.pathname.startsWith("/api/auth")
  const isPublic = ["/", "/search"].some(p => 
    request.nextUrl.pathname.startsWith(p)
  )

  if (isAuthPage || isApiAuth || isPublic) {
    return NextResponse.next()
  }

  if (!session) {
    return NextResponse.redirect(new URL("/login", request.url))
  }

  return NextResponse.next()
}

作用: 全局拦截请求，未登录用户自动重定向到登录页

执行顺序: Middleware → Pages → API Routes

🔒 安全要点

安全措施 说明 代码位置
bcrypt 哈希 密码不可逆加密，即使数据库泄露也无法还原 prisma schema + register API
JWT Secret 用于签名JWT令牌，防止伪造 .env.local NEXTAUTH_SECRET
HTTP-only Cookie JavaScript 无法访问，防止 XSS 盗取 NextAuth 配置
CSRF Token 防止跨站请求伪造攻击 NextAuth 内置
Session 校验 每个 API 和页面都验证用户身份 getServerSession()

📚 知识点总结

🔧 核心概念

  • NextAuth.js v5: Next.js 认证框架
  • Credentials Provider: 用户名密码登录
  • JWT: JSON Web Token，无状态认证
  • Session: 用户会话信息
  • bcrypt: 密码哈希算法

📁 关键文件

  • auth.ts: NextAuth 配置
  • route.ts: API 路由
  • callbacks.ts: 回调函数
  • middleware.ts: 全局拦截
  • schema.prisma: 数据模型

核心思想: 客户端不存储敏感信息，所有认证都在服务端完成
